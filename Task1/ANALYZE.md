## Аудит мер по обеспечению безопасности данных

### Список данных пациентов и как хранятся

- Каталог Patients:
    - Patients.xls - список всех пациентов: ФИО, дата рождения, телефон и электронная почта (для быстрой связи с контактом)
    - Каталог Patient-FIO-BD:
        - Медицинская карта
        - Сканы договоров
        - Сканы платёжек
        - Сканы анализов
        - Данные из расширенной формы: адрес прописки, место работы или учёбы, хронические заболевания, паспортные данные для заключения договора
- Каталог Journals:
    - Journal-Doctor-FIO.xls - запись пациентов к конкретному доктору (Doctor-FIO)
- Каталог Laboratory Registry:
    - RegistryByDate.xls - Реестр анализов за день
- 1C Бухгалтерия:
    - Платежи клиентов, полученные через KKM

### Проблемы

| **№** | **Проблема**                                                 |
| ----- | ------------------------------------------------------------ |
| 1     | Хранение данных в файлах и каталогах как есть без шифрования |
| 2     | Данные не протегированы                                      |
| 3     | Доступ к данным не разграничен                               |

### Рекомендация по технологиям и системам

Предлагается использовать Hadoop в качестве хранилища, т.к. он поддерживает не структурированные данные, хорошо масштабируется.
Также лучше дополнительно внедрить LDAP для централизованного контроля доступа к данным, настроить RBAC доступы к файлам и каталогам, шифровать диски.
Для тэгирование данных предлагается использовать Apache Atlas - Data Lineage и Data Governance. Инструмент для обеспечения прозрачности и управления данными в крупных организациях.
